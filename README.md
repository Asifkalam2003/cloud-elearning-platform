# Cloud-Based E-Learning Platform

A learning platform where instructors create courses and students enroll, study lessons, and track their progress.

## Project status

Day 1: project scope and requirements defined. Application implementation and deployment have not started.

## Planned technologies

- Frontend: HTML, CSS, JavaScript, React
- Backend: Node.js and Express
- Database: MongoDB
- Deployment: AWS

## Core features

- Registration and login
- Student and instructor roles
- Course and lesson management
- Student enrollment
- Enrollment-protected lesson access
- Lesson completion and course progress
- Student and instructor dashboards

## Day 1 learning goals

Understand browser, server, and database responsibilities; define application rules; sketch seven pages; and practice Git and GitHub.

The browser displays the interface and sends requests. The backend validates requests and enforces permissions. The database persists users, courses, lessons, enrollments, and completion records.

## Next steps

2. Learn HTML and build static pages.
3. Add CSS and responsive layouts.
